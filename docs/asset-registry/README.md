# AgentOS Asset Registry

This directory records reusable assets that have crossed a concrete extraction boundary. Entries are small machine-readable manifests pointing to canonical implementation, consumers, verification evidence, and promotion criteria.

An entry here is not merely an idea or duplicated code candidate. It should identify a canonical source and a real reuse contract.

Current entries:

- `studio-static-route-release.yaml` — reusable Studio single-route production release carrier; first consumer is Milkcat World.
