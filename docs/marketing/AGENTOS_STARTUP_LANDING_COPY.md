# AgentOS

**Persistent Intelligence. Durable Capabilities. Measurable Growth.**

AgentOS is an experimental control plane and runtime for durable AI-agent work across sessions, models, tools, and devices. We are developing a system in which task continuity, capability definitions, authority and execution evidence live outside any one model's conversational memory.

## Current engineering foundations

**Continuity — implemented and tested components.** Persistent control-plane task records, handoff records, and monotonic continuation-state checks.

**Capability governance — implemented and tested components.** Node registry, capability discovery, ownership resolution and execution governance.

**Autonomous recovery — active development.** Supervisor reconciliation, lease fencing and receipt-backed recovery are under integration. End-to-end unattended reliability is not yet generally proven.

**Verified self-growth — research.** The long-term goal is to measure improvements in success rate, intervention rate, recovery time and transfer to new tasks under controlled model and resource conditions.

## Why Claude

We intend to use Claude API and Claude Code as replaceable reasoning and coding providers, then evaluate whether AgentOS improves task reliability through persistent state, reusable capabilities and verified experience.

This is an **independent, self-funded development project**, not an incorporated company. This page is a research preview; it does not claim production availability or established self-improvement.
